# 厦门经济特区城镇化与人口流动 · 数据可视化仪表盘

单文件离线看板（ECharts 5.5.1 已内联，无任何外部依赖）。
数据源：厦门市第七次全国人口普查公报、厦门经济特区年鉴-2024、中经数据。

- 17 张图表 / 6 个 KPI / 7 张数据明细表 / 4 张民生卡片
- 覆盖三个视角：时间演变（总量）、空间分布（流向）、流动机制（动因）

## 部署

### Vercel
```bash
npm i -g vercel
vercel login
vercel --prod
```

### GitHub Pages
推送到仓库 main 分支并在 Settings → Pages 选择 main / root 即可。

### 本地
直接双击 index.html。
